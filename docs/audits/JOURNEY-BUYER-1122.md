## 已核对、无需改动

- 写入口的登录弹窗只在写动作时出现(`app.ensureLoginFor`),登录后恢复原动作且只恢复一次;通行证购买、礼品领取都带 `target` 校验。
- 过期订单会自动换幂等键重建,兜底用后端原文;场次售罄显示候补卡;所有 loading 在每个出口都会关闭。
- 代码里没有写死「1-3 个工作日」之类的退款到账时效;退款金额只来自服务端。
- 微信订单中心入口(`order-center-entry`,按 `outTradeNo`)的路由已注册;400 / 401 / 403 / 404 / 网络错误都有各自的状态和动作。

## 需 owner 拍板

- **O1 礼品链接补发**:领取链接只在购买回包里出现一次(服务端只存哈希)。「我送出的」要不要提供重新分享或撤销?这需要后端支持。
- **O2 读取失败留白规则**:全站规则是「加载失败保持空白」,本轮按本次走查的要求(不得空白或卡死),只对订单列表 / 详情改成「原因 + 重试」。要推广到其它页,还是只保留在订单页?
- **O3 付款 / 退款用语统一**:待付款状态现有「待支付 / 待付款」两种叫法,动作有「立即支付 / 去支付 / 继续付款」三种;退款动作有「取消并退款 / 申请退款(通行证单)」两种。请定一套名词和动词,下一轮全站替换。
- **O4 加座怎么卖**:加座商品是否在目录里出售?从哪一张原订单发起?
- **O5 支付成功后落在哪**:场次票付款成功后跳订单详情(2026-09-06 拍板),但成功文案写的是「票已放入票夹」,而订单详情没有去票夹的入口(V-20 删了)。是改成跳票夹,还是在订单详情加回「查看票夹」?
- **O6 取消支付是否立即释放名额**:场次结算取消微信支付会立刻取消订单并退回路线页,误触就得重新选场次和票种。是否改成留在本页、保留订单?
- **O7 「未扣款，可重试」**:支付失败面板对所有失败都这么说,包括微信侧已成功、但服务端确认失败的情况。是否只在微信支付调用本身失败时才说「未扣款」?
- **O8 「通行证」一词两用**:路线自玩门票的到账动效写「通行证已到账」,但「通行证」同时是 ¥39 / 30 天多路线通票的商品名。动效文案是 2026-10-22 owner 定稿,是否改成「门票已到账」?
- **O9 订阅消息落地页**:报名成功、开场提醒、退款通知只打开订单列表,不打开具体订单,退款通知的订单号字段还是 `AUTOREFUND` 字面量。改这些要动后端通知签名(`WxSubscribeMsgServiceImpl`)。
- **O10 活动取消的 IM 通知**:文案让玩家去「我的票夹」看订单状态,但订单在「我的订单」;点开去的还是已下架的活动页(`TeamGroupServiceImpl` 与 `system-card-target.js`)。
- **O11 队伍加入被拒**:好友用加入码入队时,如果被拒(没有票 / 队满),「接受邀请并加入」会一直是灰的,没有下一步。玩家没有票时,该把他引到哪里?
- **O12 入场码**:代码里的「入场码」是票夹里核验用的动态码,不是给好友的邀请码;好友入队用的是队伍加入码。产品上要不要把两者合并或改名?
